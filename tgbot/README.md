# Автопостер на Claude для Telegram и ВКонтакте: пошаговая инструкция

## Как это работает

```
TG-каналы + ВК-сообщества ──(каждые N часов)──▶ бот собирает новые посты
                                         │
                                         ▼
                              Claude пишет черновики
                              в стиле вашего канала
                                         │
                                         ▼
                 Черновики приходят вам в личку с кнопками
     📢 В Telegram · 🟦 Во ВКонтакте · 🚀 Везде · 🔄 Другой вариант · ❌ Отклонить
                                         │
                                         ▼
                  Бот публикует пост туда, куда вы выбрали
```

Бот обрабатывает только ваши команды и кнопки (по `ADMIN_ID`). Остальных он игнорирует.

---

## Шаг 1. Создайте бота

1. Откройте в Telegram **@BotFather** и отправьте `/newbot`.
2. Задайте имя и username (должен заканчиваться на `bot`).
3. Скопируйте токен вида `1234567890:AAAA...`. Это `TELEGRAM_BOT_TOKEN`.

## Шаг 2. Сделайте бота админом канала

1. Откройте ваш канал, затем «Управление каналом» → «Администраторы» → «Добавить администратора».
2. Найдите бота по username.
3. Оставьте ему право **«Публикация сообщений»**. Остальные права не нужны.

## Шаг 3. Узнайте свой Telegram ID

Напишите **@userinfobot**. Он пришлёт ваш числовой ID, это `ADMIN_ID`.
Затем **напишите своему боту `/start`**. Без этого бот не сможет присылать вам черновики.

## Шаг 4. Получите ключ Claude API

1. Зарегистрируйтесь на **console.anthropic.com**.
2. Пополните баланс в разделе Billing. API оплачивается отдельно от подписки Claude.ai.
3. В разделе API Keys создайте ключ `sk-ant-...`. Это `ANTHROPIC_API_KEY`.

Расход небольшой: один запуск — это один запрос с 20–30 постами на входе и несколькими постами на выходе. Текущие цены смотрите на странице Pricing в консоли.

## Шаг 5. Установите и настройте

Нужен Python 3.10 или новее.

```bash
cd tg-autoposter
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env              # Windows: copy .env.example .env
```

Откройте `.env` и заполните:

| Параметр | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из шага 1 |
| `ANTHROPIC_API_KEY` | ключ из шага 4 |
| `ADMIN_ID` | ваш ID из шага 3 |
| `TARGET_CHANNEL` | ваш канал: `@username` или `-100...` для приватного |
| `SOURCE_CHANNELS` | публичные каналы-источники через запятую, без `t.me/` |
| `DRAFTS_PER_RUN` | сколько черновиков за запуск (по умолчанию 3) |
| `RUN_EVERY_HOURS` | как часто запускаться (по умолчанию каждые 6 часов) |

Проверить, подходит ли канал-источник, просто: откройте в браузере `https://t.me/s/имя_канала`. Если видна лента постов, бот сможет её читать.

## Шаг 6. Опишите стиль канала

Отредактируйте `style.txt`. **От этого файла сильнее всего зависит качество постов.** Укажите:
- о чём канал и для кого;
- тон (на «ты» или «вы», серьёзный или ироничный);
- структуру поста и длину;
- чего избегать.

Если канал публичный, бот дополнительно подтянет ваши последние посты как примеры стиля. Со временем он будет брать в качестве примеров уже одобренные вами посты.

Файл можно менять на ходу, перезапуск не нужен.

## Шаг 6а. Подключите ВКонтакте

Если ВК вам пока не нужен, оставьте `VK_*` в `.env` пустыми: бот будет работать только с Telegram. И наоборот, если оставить пустым `TARGET_CHANNEL`, бот будет публиковать только в ВК.

### Что нужно

| Параметр | Зачем |
|---|---|
| `VK_GROUP_ID` | ID вашего сообщества. Откройте сообщество → «Управление»: в адресе будет `club123456`, нужны цифры `123456`. Если у сообщества короткое имя, ID видно в «Управление» → «Основная информация» → «Адрес» |
| `VK_TOKEN` | токен **пользователя-администратора** сообщества с правами `wall`, `groups`, `offline`. Нужен для публикации |
| `VK_READ_TOKEN` | сервисный ключ вашего приложения, для чтения источников. Необязателен: если пусто, используется `VK_TOKEN` |
| `VK_SOURCES` | сообщества-источники: `durov`, `vk.com/some_public`, `club123` |
| `VK_SUFFIX` | текст, который дописывается только к ВК-постам, например хэштеги |

### Почему нужен токен пользователя, а не сообщества

Ключ доступа, созданный в настройках самого сообщества, **не подходит** для публикации на стене: `wall.post` с ним возвращает ошибку доступа. Поэтому нужен токен администратора, полученный через приложение ВК. Бот публикует от имени сообщества (`from_group=1`), ваше имя под постом не появится.

### Как получить токен

Порядок получения токенов во ВКонтакте менялся несколько раз, и это самый капризный шаг во всей настройке. Общая схема такая:

1. Создайте приложение на платформе ВК для разработчиков (сейчас это VK ID: id.vk.com, раздел для бизнеса/разработчиков). ВК может попросить подтвердить личность, и заявке нужно время на одобрение.
2. В настройках приложения включите доступ к **стене** и **сообществам**.
3. Получите токен через OAuth, авторизовавшись **под аккаунтом администратора** вашего сообщества, с правами `wall,groups,offline`. `offline` нужен, чтобы токен не истекал через сутки.
4. Там же, в настройках приложения, скопируйте **сервисный ключ доступа** в `VK_READ_TOKEN`.

Классический способ через адрес авторизации для standalone-приложений выглядит так (подставьте ID приложения и откройте в браузере, где вы вошли в ВК):

```
https://oauth.vk.com/authorize?client_id=ID_ПРИЛОЖЕНИЯ&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=wall,groups,offline&response_type=token&v=5.199
```

После подтверждения токен будет в адресной строке после `access_token=`. Для новых приложений ВК этот способ работает не всегда. Если он не сработал, используйте авторизацию, которую предлагает документация VK ID для вашего приложения.

⚠️ **Этот токен даёт доступ к вашему аккаунту ВК.** Храните его только в `.env`, никому не пересылайте и не вставляйте на незнакомые сайты-«генераторы токенов». Если токен утёк, завершите сеансы в настройках безопасности ВК: токен перестанет действовать.

### Проверка

Запустите бота и отправьте `/status`: он покажет, какие площадки и источники подключены. Затем `/run`: если какой-то ВК-источник не читается, бот пришлёт текст ошибки от ВК.

Частые ошибки ВК:
- **`[15] Access denied`** — токен от сообщества вместо пользователя, или пользователь не админ сообщества, или у токена нет права `wall`.
- **`[5] User authorization failed`** — токен истёк или отозван. Получите новый, не забыв `offline`.
- **`[100] ... domain`** — неверное короткое имя источника.
- **`[30] This profile is private`** — источник закрытый, читать его через API нельзя.

## Шаг 6б. Настройте микс форматов постов

Бот чередует форматы, а не всегда пишет однотипные подборки. Пропорции задаются в `.env`:

```
CONTENT_MIX=podborka:40,single:20,engagement:15,seasonal:15,poll:10
```

| Формат | Что это | Совет |
|---|---|---|
| `podborka` | Подборка из 2–4 товаров на тему или бюджет | Основа ленты, даёт лучший охват |
| `single` | Подробный разбор одного товара | Работает на доверие, хорошо заходит в комментариях |
| `engagement` | Вопрос к аудитории без товаров («покажите свою находку», «1 или 2») | Сильнее всего поднимает комментарии |
| `seasonal` | Пост под ближайший праздник или повод | Claude сам ориентируется на сегодняшнюю дату |
| `poll` | Нативный Telegram-опрос | За один запуск `/run` делается максимум один опрос |

Числа — это веса, не проценты, которые обязаны давать 100: `CONTENT_MIX=podborka:2,poll:1` тоже сработает, просто опрос будет выпадать реже. Можно убрать формат совсем, задав ему `0` или не упомянув его.

Опрос публикуется как нативный Telegram-опрос (кнопки-варианты, голосование прямо в посте). **Во ВКонтакте автопубликация опросов пока не реализована** — бот пришлёт вопрос и варианты в чат, но кнопки «Во ВКонтакте» для него не будет: создайте такой опрос в сообществе вручную через «Добавить запись» → «Опрос».

Черновик опроса можно запросить и вручную: `/poll` — на случайную тему, `/poll как выбираете подарки` — с заданной темой.

## Шаг 7. Запустите и проверьте

```bash
python bot.py
```

В личке с ботом:
- `/run` — собрать посты и сразу получить черновики;
- `/topic как выбрать первый объектив` — пост на заданную тему;
- `/status` — какие площадки, источники и микс форматов подключены;
- `/poll [тема]` — написать опрос сейчас, тема необязательна;
- **ответ (reply) на черновик** текстом вроде «короче, добавь пример из жизни» — бот перепишет черновик.

Первый автоматический запуск произойдёт через минуту после старта, дальше — каждые `RUN_EVERY_HOURS` часов.

## Шаг 8. Запуск 24/7 на сервере

На домашнем компьютере бот работает, только пока компьютер включён. Для постоянной работы подойдёт самый дешёвый VPS на Ubuntu (1 ГБ RAM хватит).

```bash
# на сервере
sudo apt update && sudo apt install -y python3-venv git
# скопируйте папку tg-autoposter на сервер (scp, git и т.п.), затем:
cd ~/tg-autoposter
python3 -m venv venv && venv/bin/pip install -r requirements.txt
```

Создайте службу `/etc/systemd/system/tg-autoposter.service` (замените `ubuntu` на своего пользователя):

```ini
[Unit]
Description=Telegram autoposter
After=network-online.target

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu/tg-autoposter
ExecStart=/home/ubuntu/tg-autoposter/venv/bin/python bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now tg-autoposter
journalctl -u tg-autoposter -f      # смотреть логи
```

## Частые проблемы

- **«Chat not found» при публикации.** Бот не добавлен админом канала или неверно указан `TARGET_CHANNEL`.
- **Черновики не приходят.** Вы не нажали `/start` у бота или указали неверный `ADMIN_ID`.
- **«В источниках нет новых постов».** Бот запоминает уже обработанные посты. Дождитесь новых публикаций в источниках или добавьте ещё каналы.
- **Источник не читается.** У канала отключено веб-превью, или он закрытый. Смотрите ограничения ниже.

## Ограничения и идеи для доработки

- **Закрытые каналы** через `t.me/s/` не читаются. Для них нужна библиотека Telethon, которая работает от имени вашего аккаунта (нужны `api_id`/`api_hash` с my.telegram.org).
- **Картинки** бот не публикует, только текст. Можно добавить генерацию или подбор изображений.
- **Отложенный постинг.** Сейчас кнопки публикуют сразу. Во ВК можно использовать встроенные отложенные записи (параметр `publish_date`), в Telegram — очередь в самом боте.
- **Разные версии для площадок.** Сейчас в TG и ВК уходит один и тот же текст (плюс `VK_SUFFIX` для ВК). Можно попросить Claude готовить отдельную версию под аудиторию ВК.
- **Факты.** Claude проинструктирован не выдумывать цифры и новости, но перед публикацией всё равно проверяйте конкретику. Посты выходят от имени вашего канала.
- **Авторские права.** Бот пишет оригинальные тексты на похожие темы, а не переписывает чужие посты. Так и оставляйте: копирование чужого контента ведёт к жалобам и потере доверия аудитории.

Полностью автоматическую публикацию без вашего одобрения технически сделать легко, но на старте лучше этого не делать. Сначала посмотрите пару недель, насколько черновики попадают в ваш стиль.
